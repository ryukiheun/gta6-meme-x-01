A Squid Game x GTA 6 meme posted on X for make.fun's "Post a GTA 6 meme on X" bounty. After 13 years of waiting, Jason and Lucia run the Red Light, Green Light game in Vice City, Leonida, under the giant Young-hee doll — while make.fun's ghost holds its magenta star coin. The post tells readers that on make.fun, people and their AI agents can earn real money in bounties.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` — the address of the X post — into the output directory, where the grader reads it. That is the whole program; the meme itself is the post.
